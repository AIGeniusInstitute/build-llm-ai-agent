# 《从零构建AI Agent：大模型应用开发实践（80集视频课）》

## 前言
人工智能技术经历70年的发展已经进入成熟期，正在进入大规模应用落地阶段。在人工智能快速发展的今天，AI Agent作为一种新兴的智能系统范式，正在彻底改变我们与技术交互的方式。《从零构建AI Agent：大模型应用开发实践（80集视频课）》旨在为读者提供一个全面、深入且实用的指南，帮助他们掌握构建先进AI Agent的核心技能和知识。
作为一名长期致力于AI技术研究和应用的专家，我深感AI Agent技术的无限潜力。它不仅能够执行复杂的任务，还能够自主学习、推理和决策，为各行各业带来革命性的变革。然而，构建一个真正有效的AI Agent并非易事，它需要我们深入理解大模型的工作原理，掌握提示工程的精髓，熟练运用检索增强生成（RAG）技术，并设计出高效的Agent工作流。
本书的编写基于作者多年的研究经验和实践心得，旨在填补当前AI Agent开发领域的知识空白。本书将从基础概念出发，逐步深入到高级主题，涵盖了从理论到实践的方方面面。每一章节都经过精心设计，既有理论阐述，又有代码实例，还包含了大量的最佳实践和注意事项，以确保读者能够全面掌握相关知识。

### 内容提要
《从零构建AI Agent：大模型应用开发实践（80集视频课）》是一本全面而深入的指南，旨在帮助读者掌握构建先进AI Agent的核心技能和知识。本书涵盖了AI Agent开发的各个方面，从基础概念到高级应用，为读者提供了一个系统的学习路径。
本书共分为七大章节，系统梳理了AI Agent开发的理论基础、核心技术、实践方法与典型应用场景：
（1）AI Agent基础与理论
首章深入介绍AI Agent的定义、核心特征、技术本质及其与传统AI系统的区别，并结合典型应用场景和架构模式，帮助读者建立对Agentic AI的全面理解。通过代码示例与架构解析，读者可以直观掌握AI Agent的关键组件和实现要点。
（2）大模型与提示工程
本部分详细阐述了LLM（大模型）的发展脉络、能力边界与选型方法，系统讲解了提示工程的基础与进阶技术，包括提示设计、模板管理及优化策略。同时，深入解析了RAG（检索增强生成）的核心架构、知识库构建与系统优化，帮助读者掌握与LLM高效交互和知识增强的关键技术。
（3）开发环境与工具链搭建
本章聚焦于AI Agent开发的实际准备工作，涵盖Python环境配置、LLM API接入、主流开发框架（如LangChain）的使用，以及向量数据库、监控调试等工具链的集成。通过模块化项目结构设计与协作流程实践，为后续高效开发打下坚实基础。
（4）对话式Agent与入门项目实践
以QuickChat项目为例，详解基于LangChain的对话Agent的需求分析、模块化架构、API接口设计及多会话管理、思维链实现等核心模块开发过程，帮助读者通过实战掌握对话式AI Agent的开发方法。
（5）领域应用案例：学术研究Agent
以ArxivExplorer为例，介绍学术文献检索助手的系统架构、知识库构建、RAG集成、意图理解与多篇论文分析等关键技术，展示AI Agent在科研场景下的实际应用。
（6）领域应用案例：智能数据分析Agent
以DataInsight为例，讲解基于ReAct范式的数据分析工作流、多轮对话与上下文追踪实现，以及在销售数据分析、用户行为洞察等实际场景中的应用，帮助读者掌握AI Agent在商业数据领域的开发方法。
（7）深度研究Agent高级实践
以DeepResearcher项目为核心，系统介绍基于MCP和browser-use的深度研究Agent的技术原理、核心组件与功能实现，包括网络搜索、内容提取、报告生成、Docker部署与扩展优化等。通过多场景应用案例，展示Agent在学术、市场和内容创作等领域的创新实践。
通过上述内容，本书为读者系统呈现了AI Agent开发的理论基础、关键技术、开发流程与典型应用，既适合初学者入门，也能为有经验的开发者提供进阶参考。
